---

### How I build

- **Integrity lives in the database.** Constraints, transaction boundaries and indexes do the enforcing, not hopeful application code.
- **Hard problems first.** State, concurrency and data integrity get settled early, before they're expensive to change.
- **Every abstraction has to earn its keep.** I'd rather add structure when the code asks for it than guess at it up front.
- **Business logic stays out of the framework.** Authentication and authorisation are separate concerns.
